Karpathy's Four Rules

배경 규칙이 아닌 스테이지 진입 시 강제되는 체크포인트.

§1 · Think Before Coding
코딩 전에 생각하기
모호한 해석을 선택하고 바로 구현에 돌입하는 것을 방지
harness-start harness-brainstorm harness-debug
§2 · Simplicity First
단순함 우선
50줄로 가능한데 200줄을 작성하는 과잉 구현을 방지
harness-execute
§3 · Surgical Changes
외과적 변경
요청과 무관한 코드, 주석, 포맷을 건드리는 것을 방지
harness-execute harness-review harness-debug
§4 · Goal-Driven Execution
목표 주도 실행
현재 step을 검증하기 전에 다음 step으로 넘어가는 것을 방지
harness-plan harness-execute harness-verify
